# Attribution

XR is built on other people's open work. This file names the fonts, icons and
libraries people ask about; the desktop app lists its dependency licences in
**Settings → About → Third-party licenses**, and every
repository carries its own licence file. The page form of this list is at
`/legal/notices`.

| Project | Used in | Licence | Source |
| --- | --- | --- | --- |
| Inter | Website and desktop interface typeface | SIL Open Font License 1.1 | https://rsms.me/inter/ |
| JetBrains Mono | Code and console typeface | Apache License 2.0 | https://www.jetbrains.com/mono/ |
| Orbitron | Desktop logo and display accents | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Orbitron |
| Lucide | Icon set across website, desktop and console | ISC License | https://lucide.dev |
| Shiki | Syntax highlighting in desktop and mobile code views | MIT License | https://shiki.style |

Font files are served self-hosted or through the framework's font loader;
no font or icon request is made to a third-party tracker.
