Pairing runs the other way round from Telegram: the desktop mints the code and the user types it into Discord, because a bot cannot DM someone who has never spoken to it. The markup, class names and copy mirror desktop/src/screens/Integrations/**, and the QR images are real (generated with the same qrcode dependency the engine uses).
