⚠️ Unofficial client

WhatsApp does not offer an official API for personal accounts. XR links as a companion device using an unofficial open-source client (Baileys), exactly like a second phone you signed in from. That is against WhatsApp's terms for automated use, and accounts have been banned for it. Use a number you can afford to lose, keep the rate low, and only allow the contacts you mean to.

⚠️ Runtime not installed

WhatsApp support needs the optional @whiskeysockets/baileys runtime, which XR cannot bundle: it links against GPL-3.0 libsignal, and this project's release pipeline only ships permissive licenses. Install it where the XR daemon runs (bun add @whiskeysockets/baileys) and restart the daemon.
